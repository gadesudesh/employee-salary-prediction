💡 Key Insights

Random Forest Feature Importance
  • 📌 Years of Experience is the strongest salary driver, accounting for approximately 70.77% of model importance. More experience reliably translates to higher compensation across all roles.
  • 📌 Job Title is the second most influential factor at ~22.34%. Senior and specialized roles (e.g., C-Suite, Data Scientist Lead) command significantly higher salaries than entry-level equivalents.
  • 📌 Education Level shows a clear salary progression: High School < Bachelor's < Master's < PhD. Higher degrees unlock higher salary bands, contributing ~5.59% to model decisions.
  • 📌 Gender and Age have very low individual influence on predicted salary (0.28% and 1.01% respectively), reflecting that experience and role are far more predictive than demographic factors.

ℹ️ About This Project

Architectural breakdown, machine learning pipeline methodology, and technology stack.

🧠 System Architecture & Methodology

1
Data Ingestion & Preprocessing

Cleaned 6,700 employee records, imputed missing fields, normalized string encodings, and verified numerical distributions across age and experience.

2
Feature Transformation Pipeline

Utilized scikit-learn's ColumnTransformer to apply StandardScaler to numerical features (Age, Years of Experience) and OneHotEncoder(handle_unknown='ignore') to categorical features (Gender, Education Level, 48 Job Roles).

3
Model Selection & Hyperparameter Tuning

Trained and tuned a Random Forest Regressor (200 estimators, max depth 20), achieving 96.37% R² on unseen test data.

4
REST API & Interactive UI Deployment

Exposed via a Python Flask microservice, coupled with modern vanilla CSS & JavaScript for high responsiveness and zero unnecessary bundle overhead.

🛠️ Tech Stack

🐍 Python 3.12+ ⚡ Flask 3.1 🤖 scikit-learn 1.9 🌲 Random Forest 🐼 pandas 📊 Chart.js 🗄️ SQLite3 🎨 Modern CSS3
